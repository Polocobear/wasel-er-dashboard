# ER Crisis Command Center — build contract (spec.md)

Competition: Nexus 26, Track 3 (Informatics). Brief: during a mass emergency (highway pile-up, building fire) the ER cannot see open beds, waiting patients, equipment, staff because data sits in 10 separate systems. Deliver a centralized dashboard UI + sample code that simulates live updates and reacts to many cases, with cybersecurity/privacy, standard clinical terms, standards compliance, and innovation targeting **communication breakdowns, nurse fatigue, delayed decision-making**. Scoring: UI & data integration 40 · code 30 · standards 15 · innovation 15. Must be clutter-free and low cognitive load.

Concept: **"AI does the watching, counting and matching. Humans do the judging, treating and deciding."** Every AI action is a *suggestion* a human accepts (except optional auto-accept of bed placements). Scope covers the whole journey: detection → first responders → en route → waiting → treatment → disposition.

Deliverable: ONE self-contained HTML file. No external scripts/fonts/CDNs. Plain modern JS (ES2020), no frameworks, no build step. Files are concatenated in this order inside one `<script>`: `00-core.js`, `10-engine.js`, `20-ai.js`, `30-ui.js`. All top-level declarations share one script scope — **do not redeclare anything from 00-core.js**. `'use strict'` is already at the top of core; do not repeat it.

`10-engine.js` and `20-ai.js` MUST NOT reference `document`, `window`, or any DOM API (they are tested headless in Node by concatenating core+engine+ai and calling `init()` then `advance()` in a loop).

## Time model
- `S.t` = simulated seconds. Real loop (UI owns it): every 500 ms, `realDt = min(1, elapsed seconds)`; if `S.running`, call `step(realDt * S.speed)`.
- `step(dt)` (engine): splits dt into chunks ≤ 10 s and calls `advance(chunk)` for each.
- Speeds: 1, 10, 30 (default), 60.

## State shape (`S` from `newState()` in core) — entity fields

**Patient** `p`:
```
id 'P-1001', mrn '7-digit string', first, last, sex 'M'|'F', age, cond (COND key), src 'EMS'|'Walk-in',
esi 1..5, v {hr, sbp, rr, spo2, temp, avpu 'A'|'V'}, onO2 bool,
det bool (will deteriorate while untreated), detStart (sim t when drift begins),
stage 'inbound'|'waiting'|'treatment'|'boarding'|'done',
amb (ambulance id|null), arrivedAt (t|null), reservedBed (bed id|null),
bed (bed id|null), nurse (nurse id|null), bedAt, treatEnd, dispo (null|'discharge'|'ward'|'icu'|'or'),
boardSince, boardUntil (ward only), monitor bool, vent bool, needsVent bool, retriaged bool, diverted bool,
hist [{t, hr, sbp, rr, spo2, news}] (sampled each sim minute, max 90, ascending t),
news (int, set by assess), trend (int: news now − news ~12 min ago), flag (null | {level:'critical'|'serious', det:bool, text, hint})
```
**Bed** `b`: `{id 'R1', zone 'R'|'T'|'A'|'F', status 'free'|'occupied'|'cleaning'|'reserved', pid, until (cleaning end t), hold (suggestion id|null)}`. A bed with `hold` is free but promised to a pending suggestion; `findBed` skips held beds.

**Nurse** `n`: `{id 'N1', name, hours (on shift), status 'on'|'off'|'incoming', handover bool, arriveAt, covers (nurse id|null), offReason, offAt}`.

**Ambulance** `a`: `{id 'AMB-11', incident (incident id), pts [patient ids], dispatchedAt, sceneUntil, eta, status 'onscene'|'enroute'|'arrived'|'diverted', arrivedAt, divertedAt, prepared bool, prepBed, team}`.

**Incident**: `{id 'INC-1', name, place, via, est (expected casualties), startedAt, kind 'pileup'|'fire'}`.

**Suggestion** `s`: `{id 'S1', key (dedupe key), type, level 1|2|3 (1=critical), title, why, at (sim t created), pid?, bed?, nurse?, amb?, item?, to? (new ESI)}`.
Types: `placement, prearrival, retriage, supply, fatigue, callin, reassign, capacity, ct, vent, needvent, outage`.

**Feed** entry `{t, src, std, text}` (via `emit`). **Audit** entry `{t, role, text}` (via `audit`).

## Module 10-engine.js (Agent A) — public functions
- `init()` — `S = newState(currentSpeed)` where currentSpeed = `S ? S.speed : 30`; build beds from ZONES (all free); 14 nurses from NURSES with ids N1..N14, hours = shuffle([11.7,10.5,8.2,7.5,6.9,5.1,4.4,3.9,3.2,2.8,2.1,1.6,1.2,0.6]), status 'on'; `S.src[id]={status:'live',last:0}` for SOURCES; seed ~17 walk-in-mix patients already in treatment (arrivedAt = −rnd(20,200) min, placed silently via `place(p,b,bestNurse(p),'baseline',true)`, then treatEnd = t + rnd(8,120) min) and 3 waiting patients (arrivedAt −rnd(3,25) min); `seedHistory(p)` for each (10 per-minute samples back in time with small noise, news computed); schedule ICU step-downs for the 6 used ICU beds at rnd(25,220) min and OR finishes for 2 used at rnd(15,90) min; prefill `S.occ` with 60 samples t=−60..−1 min around current occupancy ±6; seed 8 `S.d2b` entries (t −rnd(0,55) min, m rnd(4,22)); `emit('ehr','FHIR','Gateway connected · 10 source systems streaming')`; `audit('Session started (demo sign-in)')`.
- `makePatient(condKey, src)` — vitals = COND base ± small noise (spo2 clamped ≤100), avpu 'V' with prob c.avpu, esi = rint(c.esi), det = Math.random()<c.det, detStart = t + rnd(delay) min, stage 'inbound', hist [], empty flags. Does NOT push to S.patients.
- `arrive(p)` — stage 'waiting', arrivedAt = t, `sample(p)`; emit `('adt','HL7 v2', 'ADT^A04 registered P-1001 · triage ESI 2 · <label> (ICD-10-CM <code>)')`. If `p.reservedBed` and that bed is 'reserved' for p → `place(p, bed, bestNurse(p), 'pre-arrival')` immediately (door-to-bed 0).
- `place(p, b, n, how, silent)` — b.status 'occupied', b.pid, b.hold=null; p.stage 'treatment', p.bed, p.nurse = n?n.id:null, bedAt = t, treatEnd = t + rnd(c.treat) min; unless silent: push d2b {t, m:(t−arrivedAt)/60}; resources: monitor if esi≤3 and monitorsFree()>0; vent if needs.vent and (random<needs.vent or spo2<90): if ventsFree()>0 p.vent=true else p.needsVent=true; o2 if needs.o2 (prob) → p.onO2=true and `useSup('o2',1)`; blood rint(range) → useSup; burn → useSup; ct (prob) → push to S.eq.ctQueue. p.det=false. Unless silent: emit `('beds','FHIR','Location T3 → occupied (P-1001)')` and `audit`-free (accept() audits).
- `useSup(key, n)` — qty = max(0, qty−n); log.push({t, n}).
- `leave(p, text)` — bed → 'cleaning', until t+8 min, pid null; p.stage 'done'; release monitor/vent; S.done.push({t, dispo}); remove from ctQueue; emit `('adt','HL7 v2', (dispo==='discharge'?'ADT^A03':'ADT^A02')+' P-1001 · '+text)`.
- `disposition(p)` — dispo = weighted(COND dispo); discharge → `leave(p,'Discharged home')`; else stage 'boarding', boardSince=t, ward → boardUntil = t+rnd(8,35) min; then `tryLeave(p)`.
- `tryLeave(p)` — ward & t≥boardUntil → leave 'Admitted to ward'; icu & icu.used<cap → used++, schedule step-down rnd(90,240) min, leave 'Admitted to ICU'; or & or.used<cap → used++, schedule finish rnd(60,120) min, leave 'Taken to operating room'.
- `icuStepDown()` / `orFinish()` — decrement used (≥0), emit ehr message.
- `dispatchAmb(inc, mixKey, n)` — create n patients (stage 'inbound', amb id), push to S.patients; ambulance sceneUntil = t+rnd(3,8) min, eta = sceneUntil+rnd(5,12) min, status 'onscene'; emit `('ems','CAD', 'AMB-11 on scene · 3 pts field-triaged · worst ESI 1')`. If `S.diversionUntil > t` and ambEsi(a) ≥ 4 → `divert(a)`.
- `divert(a)` — status 'diverted', divertedAt t, its patients stage 'done' + diverted=true (not counted in S.done); emit ems.
- `callIn(etaMin)` — new nurse {id 'N'+S.nextNurse++, name ONCALL[S.nextOnCall++ % len], hours 0, status 'incoming', arriveAt t+etaMin*60}; emit roster 'On-call nurse X called in · ETA n min'; return nurse.
- `nurseArrives(n)` — status 'on'; emit; if n.covers: move all of that nurse's treatment/boarding patients to n, old.status 'off', offReason 'Handed over', offAt t; emit `('roster','I-PASS','Structured handover: <old> → <new> (k patients)')`.
- `step(dt)` and `advance(d)`: t += d; runSchedule(); ambulances (onscene→enroute at sceneUntil with emit; enroute→arrived at eta: arrive() each patient, emit ems 'AMB-11 arrived · handover of k pt(s) received'); drop arrived ambulances after 2 min and diverted after 3 min; walk-ins with rate 1/7 per min + walkBoost.rate while t<walkBoost.until (60% of boosted arrivals use walkBoost.mix) → push + arrive(); for each patient `updateVitals(p, d/60)`, treatment & t≥treatEnd → disposition; boarding → tryLeave; remove stage 'done'; cleaning beds past `until` → free + emit beds 'Location A4 → available (cleaned)'; CT: each online scanner with busyUntil ≤ t and queue → shift, busyUntil = t+7 min, emit ris 'CT-2 (Radiology) scanning P-1003'; nurses 'on' hours += d/3600; incoming at arriveAt → nurseArrives; every 60 sim s: `sample(p)` for all patients and push S.occ {t, occ: bedsBusy()/beds*100} (keep 60); then **call `assessAll()` and `aiPlan()` (defined in 20-ai.js)**; every 30 s heartbeat `S.src[id].last = t` for live sources; every 20 s emit one vitals message from a random non-inbound patient: `('mon','IEEE 11073','Observation LOINC 8867-4 Heart rate = 126 /min · P-1003')`; if bedsOffline and t ≥ outageUntil → `restoreBeds()`.
- `updateVitals(p, dm)` — treatment/boarding: move hr/sbp/rr/spo2 toward {84,122,16, 97 if onO2||vent else 96} by k = 1−0.93^dm, temp toward 37 by k/2, avpu back to 'A' with prob 0.02·dm; else if det and t≥detStart: add c.drift·dm; then noise (hr,sbp ±1.5·dm, rr ±0.4·dm, spo2 ±0.3·dm); clamp hr 30–190, sbp 50–220, rr 6–45, spo2 70–100, temp 34–41.
- `sample(p)` — push {t, hr, sbp, rr, spo2, news: news2(p.v,p.onO2)}; cap 90.
- `SCEN` object with functions and `SCEN_LABEL`:
  - `pileup()` — incident('Multi-vehicle collision','E311 highway, km 42','998 call + smart traffic cameras',22,'pileup'); schedule dispatches of [3,3,2,3,2,3,2,2,2] patients at i·80 s; walkBoost {until t+50min, rate 1/4, mix 'minor'}; addBanner('MCI active · Highway pile-up · 22 casualties expected','critical','mci-pileup').
  - `fire()` — incident('Residential tower fire','Tower B, Sector 4','997 call + building fire-alarm link',15,'fire'); [3,2,3,2,2,3] at i·90 s mix 'fire'; walkBoost {40 min, 1/6, 'fireMinor'}; banner critical 'mci-fire'.
  - `staff()` — 3 'on' non-handover nurses with highest load → status 'off', offReason 'Redeployed to ICU', offAt; emit roster; banner serious 'staff'.
  - `equipment()` — CT-1 offline; ventFaulty += 2; emit ris 'CT-1 (ED) reported offline: gantry fault', emit rtls 'Ventilators V-03, V-08 failed self-test'; banner serious 'equip'.
  - `outage()` — bedsOffline true, bedsFallback false, bedsSnapshot = deep copy of beds, bedsSnapAt t, outageUntil t+25 min, S.src.beds.status 'offline'; push feed directly (emit would drop it): `S.feed.unshift({t,src:'beds',std:'FHIR',text:'Bed management interface not responding (timeout)'})`; banner serious 'outage'.
  - `incident(name, place, via, est, kind)` helper pushes to S.incidents, emits `('ems','CAD','INC-1 detected via <via>: <name>, <place> · est. <est> casualties')`.
- `runScenario(id)` — SCEN[id](); audit('Scenario started: '+SCEN_LABEL[id]).
- `restoreBeds()` — count beds whose status differs from snapshot; bedsOffline=false, bedsFallback=false, src.beds 'live'; emit beds 'Bed management feed restored · k bed changes reconciled'; clearBanner('outage').

## Module 20-ai.js (Agent B) — public functions
- `assessAll()` — `for p of S.patients: assess(p)`.
- `assess(p)` — p.news = news2(p.v,p.onO2); ref = first hist sample with t ≥ S.t−12 min (hist ascending); p.trend = ref ? news−ref.news : 0. Change parts if ref and S.t−ref.t ≥ 4 min: HR rise ≥15 → 'HR 94→126'; SBP fall ≥12 → 'SBP 118→92'; SpO₂ fall ≥3 → 'SpO₂ 96→91%'; RR rise ≥6. untreated = stage waiting|inbound. Flag rules (first match): untreated && parts && (trend≥2 || news≥5) → {level:'critical', det:true, text:'Deteriorating: '+parts.join(', ')+' in N min', hint: pattern}; untreated && news≥7 → critical det:true 'NEWS2 7: urgent clinical review'; untreated && news≥5 → serious det:false 'NEWS2 5: review within 30 min'; boarding > 20 min → serious 'Boarding 25 min: awaiting ICU bed' (use DISPO_LABEL). Pattern: HR↑&SBP↓ → temp≥38 ? 'Pattern consistent with septic shock' : 'Pattern consistent with internal bleeding / shock'; SpO₂↓ or RR↑ → 'Pattern consistent with respiratory deterioration'; else 'Physiological trend worsening'.
- `priority(p)` — (6−esi)·20 + news·4 + max(0,trend)·6 + (waiting ? min(waitMin,60)·0.4 : 0) + (flag critical ? 25 : 0).
- `findBed(p)` — first bed in ZONE_PREF[p.esi] order with status 'free' and no hold.
- `nurseLoad(n)` — Σ W_ESI[esi] of patients with nurse===n.id in treatment|boarding. `heldLoad(n)` — Σ W_ESI of patients in pending placement suggestions targeting n.
- `bestNurse(p)` — candidates status 'on' && !handover; score = load+held+W_ESI[p.esi]; +1 if score>1.15; +0.25 if hours≥10; +0.6 if hours≥12; min score wins (null if none).
- `fatigueLevel(n)` — 'over' (≥12 h) | 'tired' (≥10 h) | 'ok'.
- `orphans()` — treatment|boarding patients whose nurse is null or not status 'on'.
- `minutesLeft(key)` — usage in last 30 sim-min / 30 = rate per min; null if rate 0; else round(qty/rate).
- `committed(key)` — expected need of inbound+waiting patients: blood/burn = mean of needs range, o2 = needs.o2 probability; rounded.
- `forecast()` — busy = bedsBusy(); waitingN; walk = current walk-in rate/min; for m=0..30: arrivals = patients on non-arrived/non-diverted ambulances with eta ≤ t+m·60, + walk·m; leaving = treatment patients with treatEnd ≤ t+m·60 × 0.75 + boarding × min(1,m/30) × 0.5; demand = busy + waitingN + arrivals − leaving; pts.push({m, occ: max(0, demand/beds·100)}); fullIn = first m with demand > beds (null if none). Return {pts, fullIn}.
- `aiPlan()` — in this order:
  1. drop suggestions failing `stillValid(s)` (via `dropSugg`, which releases `bed.hold` if it equals s.id).
  2. `S.fc = forecast()`.
  3. **retriage**: untreated p with flag.det; to = (news≥9 || sbp≤85) ? 1 : 2; only if to < esi. level 1. title 'Re-triage P-1037 from ESI 3 to ESI 2'; why = flag.text + '. ' + hint + '. NEWS2 n.'
  4. **prearrival**: ambulances onscene|enroute, !prepared, ambEsi ≤ 2, eta−t ≤ 15 min: most acute patient, findBed → hold bed. level 1 if ESI 1 else 2. title 'Prepare for AMB-14: reserve Resus R2, page trauma team' (team = COND.team || 'resus team'); why 'ETA 6 min · field triage ESI 1 · <label>. Bed and team ready before the doors open.'
  5. **bed stealing**: for waiting patients (by priority desc) with no placement and no free bed: if a pending placement holds a bed in this patient's ZONE_PREF for a patient with priority < this − 15, drop that (lowest-priority) one.
  6. **placement**: waiting patients without reservedBed, sorted by priority desc, key 'placement:'+id: findBed + bestNurse; hold bed; level ESI≤2→1, ESI3→2, else 3; title 'Place P-1043 (ESI 2) in Trauma T3 with A. Haddad'; why e.g. 'Trauma bay matches ESI 2 · waited 14 min · A. Haddad lightest load (45% → 95%), 3.2 h on shift · monitor M-12 free nearby (RTLS)'.
  7. **supply** per S.sup item (skip if pending): low = qty ≤ cap·0.25, short = committed > qty, fast = minutesLeft < 45 → title = sp.ask; why '9 units left · ~22 min at current use · waiting + inbound patients likely need ~12'; level 1 if short or <20 min else 2.
  8. **reassign** if orphans().length (level 1): 'Reassign 5 patients left without a nurse'; why 'Balanced by ESI-weighted workload and hours on shift; structured I-PASS handover sent to each new nurse.'
  9. **fatigue** for nurses on, !handover, hours ≥ 12 (level 2): 'Relieve S. Fernandes (12.1 h on shift): call in on-call nurse'.
  10. **callin** if (avg load of on/!handover nurses > 0.85 or their count ≤ 11) and no 'incoming' nurses (level 2): 'Call in 2 on-call nurses'.
  11. **capacity** if fc.fullIn !== null && ≤ 20 && diversionUntil ≤ t (level 1): 'Divert ESI 4–5 ambulances to nearby EDs for 45 min'; why 'ED beds full in ~12 min: 3 free, 6 waiting, 9 inbound. Critical patients still come here.' (fullIn 0 → 'full now').
  12. **ct** if CT-1 offline && !ctRepair (level 2); **vent** if ventFaulty>0 && !ventLoan (level 2) 'Borrow 2 ventilators from the anaesthesia pool'; **needvent** per patient needsVent && !vent (level 1); **outage** if bedsOffline && !bedsFallback (level 1) 'Bed management feed offline: switch to backup bed sensors'.
  13. If `prefs.autoAccept`: accept every placement suggestion with actor 'auto'.
  Skip any key that is `blocked(key)` = already pending or `S.dismissed[key] > S.t`. New level-1 suggestions push their title to `S.announce` (array of strings; UI reads & clears it for the screen-reader live region).
- `addSugg(obj)` assigns id 'S'+nextSugg++, at = t; `dropSugg(s)`; `blocked(key)`; `stillValid(s)` (placement: patient waiting & bed free & hold===s.id; prearrival: ambulance not arrived/diverted & bed free & hold===s.id; retriage: patient untreated & esi > s.to; supply: !pending; fatigue: nurse on & !handover; reassign: orphans exist; callin: age < 20 min; capacity: diversionUntil ≤ t; ct: CT-1 offline & !ctRepair; vent: ventFaulty>0 & !ventLoan; needvent: patient needsVent & !vent; outage: bedsOffline & !bedsFallback).
- `accept(s, actor)` — actor 'manual'|'auto'|'bulk'. Effects: placement → place(p, bed, nurse still on&!handover ? it : bestNurse(p), actor); prearrival → bed 'reserved', pid, hold null, p.reservedBed, amb.prepared/prepBed/team, emit beds 'Location R2 → reserved for P-1050 (AMB-14)' and emit roster 'Paging' '<team> paged to R2 for AMB-14'; retriage → p.esi = s.to, retriaged, emit ehr 'Encounter P-1037 priority updated → ESI 2'; supply → pending, emit pharm 'SupplyRequest …', schedule 15 min: qty = min(cap, qty+restock), pending false, emit pharm 'GS1' received; fatigue → nurse.handover = true, cover = callIn(20), cover.covers = nurse.id; callin → callIn(25) ×2; reassign → each orphan gets bestNurse, emit roster 'I-PASS'; capacity → diversionUntil = t+45 min, divert inbound ambulances with ambEsi ≥ 4, emit ems; ct → ctRepair true, emit ris, schedule 30 min CT-1 online + ctRepair false + emit; vent → ventLoan true, schedule 10 min: ventFaulty = 0, ventLoan false, emit rtls; needvent → p.vent true, needsVent false, eq.vents += 1, emit rtls; outage → bedsFallback true, emit beds. Then `audit((actor==='auto'?'Auto-accepted (policy): ':'Accepted: ')+s.title)` and dropSugg(s). Return true/false.
- `dismiss(s)` — S.dismissed[s.key] = t + 10 min; audit('Dismissed: '+title); dropSugg.
